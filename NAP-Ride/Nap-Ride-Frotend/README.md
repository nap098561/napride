# NAP Ride Frontend

Frontend implementation for the NAP Ride campus mobility platform using HTML, CSS and vanilla JavaScript.

## Structure

- `student/` — student registration, login, dashboard, booking, tracking, history and profile
- `driver/` — driver registration, login, dashboard, ride requests, active ride, earnings and profile
- `admin/` — admin login, dashboard, drivers, students, live rides, reports and complaints
- `css/` — shared application styling
- `js/` — shared UI interactions
- `assets/` — images, icons and future static assets

## Backend integration

This repository contains frontend code only.

The backend team can connect:
- authentication forms
- registration forms
- route and driver availability
- ride booking
- ride status updates
- live GPS data
- student and driver profiles
- ride history
- payment methods
- commission settings
- reports and analytics
- complaints and account actions

Form fields include names/IDs where appropriate to make API integration straightforward.

## Run locally

Open `index.html` in the browser or use VS Code Live Server.
